# Work packages

Work packages turn the product direction in [`CLAUDE.md`](../../CLAUDE.md) into scoped, verifiable pieces of work.
Each round lives in its own folder with its own README. Every package is a **suggestion** until Xelnath or Sungkuk
adopts it. Numbering runs across rounds, so a package number always means one package.

| Round | Folder | Packages | State |
|---|---|---|---|
| UX, October 2026 | [`ux-2026-10/`](ux-2026-10/README.md) | WP-01 to WP-11 | Archived, with an implementation record per package |
| Performance, October 2026 | [`performance-2026-10/`](performance-2026-10/README.md) | WP-12 to WP-24 | Current, all Suggestion |

A new round gets a new folder named `<topic>-<yyyy-mm>/` and continues the numbering.
