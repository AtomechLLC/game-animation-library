# Repository instructions

Use [CLAUDE.md](CLAUDE.md) for the project's enduring product direction and [README.md](README.md) for workflows.

## Keep classification architecture current

[The classification architecture](docs/architectgure/architecture.md) documents the current Action Atlas implementation in English, with Markdown and Mermaid.

When changing classification fields or IDs, domain assignment, category membership, cross-listing, filtering, classification display/navigation, or the data generation and page rendering paths, update this document in the same change. Keep its prose, examples, diagrams, category table and affected counts consistent with the implementation. Check its relative links and Mermaid syntax.

A clip-only replacement that does not affect the documented structure or facts does not require a documentation update. This is a contributor requirement; there is no automatic documentation generation or CI synchronization check.
